# Candidatos: lo que mejor anda, congelado

Copias congeladas y autónomas de lo que mejor funciona, con todo lo necesario para compilar y correr. Se cargan cuando algo anda bien.

- `VERSIONES.md`: índice (cuál es cuál, de dónde salió, en qué anda mejor).
- `NOMBRE/`: una versión (LEEME.md, ESTADO.md, COMO_CORRER.md).
- `congelar_version.sh`: crea una versión nueva desde ramas/commits (`bash candidatos/congelar_version.sh NOMBRE`).

Reglas: una versión congelada no se edita; lo que cambia va a una versión nueva; el día de la competencia se corre solo algo de esta carpeta.
