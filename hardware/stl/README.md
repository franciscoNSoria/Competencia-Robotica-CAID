# STL originales

Acá van los STL **tal como los entregó la organización**, sin modificar. Son la referencia para
imprimir y para medir.

- No editar estos archivos. Si hace falta una versión modificada (por ejemplo, para el URDF), se
  exporta de nuevo desde el CAD y se guarda en otro lugar.
- Mantener los nombres originales. La codificación de piezas es `ARM2-CUDAR-<conjunto>-<subconjunto>-<pieza>`
  (ver `../bom/Lista_de_partes.ods`):
  - `ARM2-CUDAR-0-1-*`: brazo
  - `ARM2-CUDAR-0-2-*`: chasis
  - `ARM2-CUDAR-0-3-*`: cámara
- Si un archivo pesa más de 50 MB, avisar antes de subirlo: conviene usar Git LFS.
